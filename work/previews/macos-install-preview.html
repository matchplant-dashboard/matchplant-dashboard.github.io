Run MatchPlant locally

Download once. Launch from your computer.

The dashboard opens in your browser. Processing and native GUI tools run on your machine.

Download MatchPlant ZIP ↗ Unzip it, then open the dashboard folder.

macOS

  1. Double-click setup.command once.
  2. Double-click start_dashboard.command whenever you want to use MatchPlant.

Windows

  1. Double-click setup.bat once.
  2. Double-click start_dashboard.bat whenever you want to use MatchPlant.
macOS installation help: “setup.command” Not Opened

macOS could not verify the file, so setup has not started. First confirm your download came from the official MatchPlant repository ↗.

  1. Click Done in the warning.
  2. Open System Settings → Privacy & Security and scroll to Security.
  3. Click Open Anyway for setup.command, then confirm Open.

If Open Anyway is missing, double-click the file again and return to Privacy & Security. When setup finishes, open start_dashboard.command; repeat these steps if macOS blocks it too. See Apple’s instructions ↗

Local dashboard: It opens automatically at 127.0.0.1:5050 after you start it.

First time here?

  1. Download the dashboard from MatchPlant-Dashboard on GitHub.
    Link: Download ZIP
  2. Unzip it, then double-click the setup file. One-time only.
    • Mac: setup.command
    • Windows: setup.bat
  3. Double-click the start file to start the dashboard. Do this every time you want to use it.
    • Mac: start_dashboard.command
    • Windows: start_dashboard.bat

Step 3 opens the dashboard automatically. If it doesn't, reload this page, or open http://127.0.0.1:5050 yourself.

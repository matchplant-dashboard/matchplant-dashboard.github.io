First time here?

  1. Download the dashboard from MatchPlant-Dashboard on GitHub (Code → Download ZIP).
  2. Unzip it, then double-click setup.command (Windows: setup.bat). One-time only.
  3. Double-click start_dashboard.command (Windows: start_dashboard.bat) to start it — do this every time you want to use the dashboard.

Once it's running, this page will find it automatically — or just go to http://127.0.0.1:5050 directly.

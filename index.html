The pipeline

Four stages from image to insight.

Use the modules you need, in a pipeline that connects field imagery to spatial data.

  1. 01Prepare imagery
  2. 02Build the dataset
  3. 03Train and test
  4. 04Locate and analyze
01 / Preprocess

Prepare imagery

Embed GPS data, locate control points, and generate an orthomosaic.

  1. 0GPS Embedder
  2. 1GCP Finder
  3. 2ODM Runner
02 / Dataset

Build the dataset

Select, annotate, tile, and split UAV images.

  1. 3Minimum Image Finder
  2. 4BBox Drawer
  3. 5Image Splitter
03 / Model

Train and test

Train from scratch or fine-tune a model, then evaluate detections.

  1. Choose one training route
  2. 6-1Object Detection Trainer
  3. or
  4. 6-2Transfer Learning
  5. 7Object Detection Tester
04 / Output

Locate and analyze

Project detections and extract spatial traits.

  1. 8Image-to-Ortho Projector
  2. 9Spatial Stats Extractor

11 tools across four stages. The two training routes at step 6 are alternatives; use whichever fits your data.

Run MatchPlant locally

Download once. Launch from your computer.

The dashboard opens in your browser. Processing and native GUI tools run on your machine.

Download MatchPlant ZIP ↗Unzip it, then open the dashboard folder.

Mac

  1. Double-click setup.command once.
  2. Double-click start_dashboard.command whenever you want to use MatchPlant.

Windows

  1. Double-click setup.bat once.
  2. Double-click start_dashboard.bat whenever you want to use MatchPlant.

Local dashboard: It opens automatically at 127.0.0.1:5050 after you start it.

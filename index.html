Four stages from image to insight.

Use the modules you need, in a pipeline that connects field imagery to spatial data.

Run MatchPlant locally

Download once. Launch from your computer.

The dashboard opens in your browser. Processing and native GUI tools run on your machine.

Download MatchPlant ZIP ↗Unzip it, then open the dashboard folder.

Mac

  1. Double-click setup.command once.
  2. Double-click start_dashboard.command whenever you want to use MatchPlant.

Windows

  1. Double-click setup.bat once.
  2. Double-click start_dashboard.bat whenever you want to use MatchPlant.

Local dashboard: It opens automatically at 127.0.0.1:5050 after you start it.
